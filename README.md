# Discord Broadcast Bot (البرودكاست بوت)

منظومة برودكاست متطورة ومصممة خصيصاً لإرسال الرسائل الجماعية عبر سيرفرات ديسكورد باستخدام تقنية توزيع الحمل (Load Balancing) عبر عدة بوتات وحسابات في نفس الوقت وبسرعة عالية.

---

## مميزات المشروع

- **إدارة غير محدودة للتوكنات:** إمكانية ربط أي عدد من التوكنات وتوزيع مهام الإرسال بينها بالتناوب لتفادي حظر الديسكورد والـ Rate Limits.
- **دعم ملفات TXT:** سحب وإفلات أو رفع ملف `.txt` يحتوي على التوكنات واستخراجها وفحصها مباشرة بنقرة واحدة.
- **حفظ تلقائي (Persistence):** حفظ التوكنات والبيانات تلقائياً على السيرفر واسترجاعها عند إعادة التشغيل.
- **كونسول وتتبع فوري:** شاشة Console ذكية تبث حالة الإرسال في الوقت الفعلي عبر WebSockets مع إحصائيات دقيقة (ناجح / فاشل / متبقي / الإجمالي).
- **إعادة محاولة ذكية (Auto Retry):** زر مخصص لإعادة فحص وتوصيل أي توكن يتعرض لمشكلة مؤقتة دون الحاجة لإعادة كتابته.
- **تخصيص الرسائل:** دعم المتغيرات التلقائية مثل منشن العضو `{user}` واسمه `{username}` واسم السيرفر `{server}`.
- **تصميم Dark احترافي:** واجهة مستخدم مبنية بأسلوب معاصر بدون أي إيموجيات ومعتمدة بالكامل على أيقونات Lucide الاحترافية وخطوط Google الرسمية.

## متطلبات التشغيل

- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم npm

---

## التثبيت والتشغيل

1. **تحميل المستودع:**
```bash
git clone https://github.com/Zyntrix-code/Broadcast-bot.git
cd Broadcast-bot
```

2. **تثبيت الحزم المطلوبة:**
```bash
npm install
```

3. **تشغيل السيرفر:**
```bash
npm start
```
أو عبر الضغط المباشر على ملف `run.bat` على نظام ويندوز.

4. **فتح لوحة التحكم:**
افتح متصفحك وتوجه إلى:
```
http://localhost:3000
```

## كيفية الاستخدام

1. **إضافة التوكنات:** ضع توكن البوت أو الحساب في خانة التوكنات واضغط إضافة، أو اضغط على رفع ملف `.txt` لإدراج مئات التوكنات دفعة واحدة.
2. **كتابة الرسالة:** اكتب الرسالة المراد نشرها في خانة المحتوى، ويمكنك استعمال أزرار المتغيرات لإدراج المنشن التلقائي.
3. **تحديد السيرفر والأعضاء:** ضع معرّف السيرفر (Server ID) واضغط على "فحص السيرفر والأعضاء" للتأكد من وصول البوتات للأعضاء، ثم حدد العدد المستهدف أو اتركه فارغاً للإرسال للجميع.
4. **بدء الحملة:** اضغط على "بدء البرودكاست الآن" وتابع شاشة الكونسول وشريط التقدم في الوقت الفعلي.
